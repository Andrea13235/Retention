# ⚡ RETENTIONVOLT

Piattaforma di reference intelligence, cadenza di taglio e motion design per video editor, YouTuber e agenti AI di video editing ("il Mobbin per il video editing").

## 📂 Struttura del Progetto

```
retentionvolt/
├── mcp reference video editing/     # Web App Next.js 14, UI, API MCP e script analitici
│   └── design/                      # App Router Next.js, Tailwind CSS, Lucide Icons, /api/mcp
├── campagna-social/                 # Strategia di lancio e crescita organica virale
│   ├── 01_PIANO_STRATEGICO_VIRALE.md
│   ├── 02_PIANO_X_REDDIT_ASTRA.md
│   └── README.md
└── supabase/                        # Configurazione del database cloud Supabase
    └── .temp/linked-project.json
```

## 🚀 Avvio Rapido

```bash
# Entra nella directory dell'applicazione web
cd "retentionvolt/mcp reference video editing/design"

# Avvia il server di sviluppo
npm run dev
```

L'applicazione è accessibile localmente su `http://localhost:3000`.
Il server MCP nativo risponde su `http://localhost:3000/api/mcp`.
